# Breeze POC - Lob Hero

26赛季吊射英雄车的breeze先行开发

## 结构简要介绍

- common: 上下板通用代码. 比如说板间通信协议.
- up: 上板. 使用 `RM-TypeC`
- down: 下板. 使用 `RM-TypeC`
- test: 测试.

## 上下板职责

Up 安装在头上, 负责:
- 与上位机通信
- 与图传通信, 自定义客户端通信, 自定义控制器通信也算在内
- 控制头上的传感器和电机
- 控制摩擦轮

Down 安装在底盘, 负责:

- 与裁判系统通信, 电源管理和裁判系统多机通信都算在内
- 控制底盘的传感器和电机
- 控制拨盘
- 读取遥控器数据并控制总体运动状态
